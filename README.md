# Présentation PLANOGEC

PLANOGEC est un outil de communication pour l'Ogec de l'école Sainte-Marie à Saint-Etienne-de-Montluc. Il permet de centraliser la gestion des événements, des tâches et des administrateurs de l'association, et propose une interface simplifiée à présenter lors des Conseils d'Administration mensuels.

Dans cette première version, l'application est centrée sur la Commission Vie Collective.

---

## Prérequis

Avant de commencer, installez les outils suivants sur votre poste :

- [Git](https://git-scm.com) — gestionnaire de versions (sorte de drive pour partager des codes)
- [Node.js](https://nodejs.org) — moteur d'exécution JavaScript

---

## Installation

### 1. Première installation

Téléchargez le fichier `setup.bat` depuis cette page en cliquant dessus puis sur le bouton "Download raw file" (icône de téléchargement en haut à droite).

Double-cliquez ensuite sur `setup.bat`.

Ce script va :
- Télécharger le projet complet depuis GitHub
- Installer toutes les dépendances nécessaires automatiquement

---

### 2. Lancer l'application

Double-cliquez sur `lancer.bat`.

Ce script va :
- Démarrer le serveur backend (gestion de la base de données)
- Démarrer l'interface frontend (gestion de l'interface visible par l'utilisateur)
- Ouvrir automatiquement PLANOGEC dans votre navigateur

> L'application s'ouvre sur `http://localhost:3000`. Pour un affichage optimal, utilisez Google Chrome.

---

### 3. Mettre à jour l'application

Lorsque le développeur vous informe d'une mise à jour, double-cliquez sur `maj.bat`.

Ce script va :
- Récupérer la dernière version du projet depuis GitHub
- Mettre à jour les dépendances si nécessaire
